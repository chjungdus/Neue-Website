# Logo

Hier liegt das Website-Logo. Zum Austauschen einfach die Dateien ersetzen — die Dateinamen müssen gleich bleiben:

- `logo-placeholder.svg` — dunkle Variante (für helle Hintergründe, z. B. Navigation nach dem Scrollen)
- `logo-placeholder-white.svg` — helle Variante (für dunkle Hintergründe, z. B. Hero und Footer)

Empfohlene Höhe: 32 px (Breite flexibel). SVG bevorzugt, PNG funktioniert ebenfalls (dann die Dateiendungen in `src/components/layout/navbar.tsx` und `src/components/layout/footer.tsx` anpassen).
